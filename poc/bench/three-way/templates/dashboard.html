扣除每一個 Cargo 命令

包含初始化、skill probe-build、cell 編譯、library test gate、專案 build/test 與失敗重試。cargo test 整個命令都扣除，包含測試時間。

Python 版本也可能有 Cargo

Python cell 不需 Rust→Wasm 編譯，但 Rust 專案的共同 checker 仍會執行 Cargo。依實際命令計算，不依版本假設扣除 0 ms。

同時執行只扣一次

先取所選 Cargo／AOT 命令時間區間的聯集，再截取所選耗時期間。Checker 在 agent 完成後，僅從「含 checker」的時間扣除。

這是實際執行紀錄的算術扣除，不是免編譯重跑。AOT 組每次 cell 由 host 從已驗證、移除 custom sections 的 Wasm 重新編譯，不使用 AOT cache；interpreter 保留為獨立組。剩餘時間包含模型生成、source 準備、排隊、runtime、snapshot 與 wrapper 啟動成本。舊 run 沒有完整 Cargo 起訖紀錄，顯示「量測不足」，不能回填另一輪的時間。

逐次 run 扣除明細

扣除後時間 = 原始時間 − 所選期間內、所選 Cargo／AOT 命令的合併 wall time。「沒有 Cargo 呼叫」必須有完整捕捉紀錄證明；「無法計算」代表缺少完整量測。

Python cell 與 Rust cell 執行時間

Cell 執行明細 CSV

使用 Python kernel 的 cell.python_execute 與 Rust runner 的 cell.execution 回報值。排除模型生成、Cargo、Wasm→AOT 編譯、workspace 初始化與 snapshot。Python 重用已啟動的 kernel；Rust 每個 cell 啟動新的 WasmEdge process，包含 module 載入、VM 初始化、所選 interpreter / AOT 執行、I/O 與 host bridge 成本，並非純程式本體時間。不同版本生成的 cell 程式與次數可能不同，請一起查看呼叫數與來源。平行 cells 的合計是工作量加總，不是牆鐘時間。
